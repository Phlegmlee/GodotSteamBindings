### Getting started
Install the GodotSteam C# Bindings by adding the addon to your project's addons folder.

## Why is this separate?
This project was orignally forked from [the original](https://github.com/LauraWebdev/GodotSteam_CSharpBindings) to make contributions back. I then made so many changes to the structure that it did not make sense to remain on the fork network.

## Contributions
Please direct any contributions back to [the original](https://github.com/LauraWebdev/GodotSteam_CSharpBindings) project, if you do not wish to do so, contributions made here will be recontributed to the the original by myself with your contribution credited appropriately.
